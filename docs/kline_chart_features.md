# K 线图功能说明

## 📊 专业 K 线图表

使用 **Lightweight Charts** (TradingView 开源库) 实现专业的金融图表，完全模仿 SteamDT 的大盘展示效果。

## ✨ 功能特性

### 1. **交互式 K 线图**
- ✅ 鼠标滚轮缩放：放大/缩小查看不同时间范围
- ✅ 鼠标拖动：左右拖动查看历史数据
- ✅ 十字光标：鼠标悬停显示当前时间点的详细数据
- ✅ 自动缩放：自动调整到最佳视图范围

### 2. **实时数据显示**
顶部信息栏显示：
- 时间：最新数据时间
- 开：开盘价
- 高：最高价
- 低：最低价
- 收：收盘价
- 涨幅：涨跌幅度和百分比
- 成交量：总商品数

### 3. **涨跌统计**
三个统计卡片：
- 上涨商品数（红色）
- 持平商品数（灰色）
- 下跌商品数（绿色）

### 4. **各类别指数**
显示各类别（匕首、步枪、手套等）的指数和涨跌幅

### 5. **热门板块**
显示热门板块的指数和涨跌幅

## 🎨 视觉效果

### K 线颜色
- **红色**：上涨（收盘价 > 开盘价）
- **绿色**：下跌（收盘价 < 开盘价）

### 图表特性
- 白色背景，清晰易读
- 灰色网格线
- 十字光标跟随鼠标
- 时间轴显示日期和时间
- 价格轴显示指数值

## 🖱️ 操作指南

### 缩放
- **鼠标滚轮向上**：放大（查看更详细的数据）
- **鼠标滚轮向下**：缩小（查看更长时间范围）

### 拖动
- **鼠标左键拖动**：左右移动查看历史数据

### 查看详情
- **鼠标悬停**：十字光标显示当前时间点的 OHLC 数据
  - O (Open): 开盘价
  - H (High): 最高价
  - L (Low): 最低价
  - C (Close): 收盘价

### 重置视图
- **双击图表**：重置到默认视图
- **点击"刷新"按钮**：重新加载最新数据

## 📡 数据来源

K 线图数据来自 SteamDT API：
```
GET /user/statistics/v2/chart
```

数据格式：
```javascript
{
  "time": 1732896000,  // Unix 时间戳（秒）
  "open": 1301.99,     // 开盘价
  "high": 1302.61,     // 最高价
  "low": 1302.02,      // 最低价
  "close": 1302.61     // 收盘价
}
```

## 🔄 自动刷新

- 页面每 **30 秒** 自动刷新一次数据
- 点击右上角"刷新"按钮可手动刷新

## 🛠️ 技术栈

- **Lightweight Charts**: TradingView 开源的轻量级图表库
- **原生 JavaScript**: 无需额外框架
- **FastAPI**: 后端 API
- **MongoDB**: 数据存储
